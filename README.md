# ebb-imageedit
Ripper and Compiler for EarthBound Beginnings.

`python3 extractor.py e` to extract assets.
`python3 extractor.py r` to recompile (and at some point, link) assets.

Currently not bytematching (just gfx bugs) and not shiftable.

The latter is just because i don't have a good linking solution yet. When that gets fixed, all will be well.
